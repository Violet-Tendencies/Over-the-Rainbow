# Over the Rainbow
This is a DATAPACK intended to be used WITH [Spectrum by Dafuqs](https://github.com/DaFuqs/Spectrum)

This datapack aims to add access to currently WIP items that have functionality, but no way to get them in-game.
Most, if not all, of these recipes are only accessible in the current endgame of Spectrum.
This datapack has been tested to work with Spectrum version `1.12.9` and most likely works with `1.13.0`, the formatting of the new guidebook entries fitting with the latter.

## Disclaimer:
This datapack does contain some relatively visceral entries. Work is being done to allow for more tame versions of said entries, but these alternatives are not implemented yet.

## Additions:
- 1 new enchantment!
- 5 new & 3 updated Colorful World entries!
- 10 new recipes!
- Access to A `Wonderful` Idea! :)
- A few things you'll have to see yourself!
  
With more on the way!

## Installation Guide:
As some of the advancements in this datapack are gated behind advancements, if you already have said advancements (in, say, a preexisting world) it'll be impossible for you to get them.

HOWEVER! There is a fix:

before adding datapack:

run `/advancement revoke @a only spectrum:unlocks/blocks/memories`

run `/advancement revoke @a only spectrum:endgame/spectrum_endgame`

[adding the datapack](https://minecraft.wiki/w/Tutorial:Importing_a_data_pack)

after adding datapack:

run `/advancement grant @a only spectrum:unlocks/blocks/memories`

run `/advancement grant @a only spectrum:endgame/spectrum_endgame`


And you'll be good to go! Sadly, I do not know a way around this aside from playing on a new save with this datapack installed from the start.

### "I did a thing but nothing popped up in the book!"
Before panicing, try `/modonomicon modonomicon reset spectrum:guidebook`, this is due to the guidebook being finicky with advancements being added mid-playthrough. This command will NOT erase any progress you may already have.
